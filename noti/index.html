เครื่องนี้ไม่เคยลงแอปดักมาก่อน — ข้ามหัวข้อนี้ได้เลย กดเลือกเครื่องข้างบนแล้วทำตามคู่มือ

↻
เคยลง VTN Notify ไว้ — ย้ายตามลำดับนี้
  1. เปิดแอปเก่า ดูให้แน่ว่าขึ้น “ปกติ” ไม่ใช่ “ค้างส่ง N รายการ”
    ยังค้าง = ยังมีโนติที่ส่งไม่สำเร็จอยู่ในเครื่อง ถอนแอปทิ้งตอนนี้ของหายเลย ต่อเน็ตแล้วรอจนเลขเป็น 0 ก่อน
  2. ก๊อป URL เตรียมไว้ก่อน (จากหน้าตั้งค่าในระบบ) แล้วส่งเข้าไลน์/โน้ตตัวเอง
    URL ตัวเดิมใช้ได้ ไม่ต้องออกใหม่ — แต่แอปใหม่จำของเก่าไม่ได้ ต้องวางเองอีกรอบ · แอปใหม่มีช่อง URL กับ รหัส (โทเคน) แยกกัน ก๊อปทีละช่องได้เลย
  3. ถอนแอปเก่าออก
  4. ลงแอปใหม่ตามคู่มือ (กดเลือกเครื่องข้างบน)
⚠️

ทำสลับขั้นแล้วของหาย กู้ไม่ได้ — โนติที่ค้างอยู่ในแอปเก่าจะหายไปพร้อมกับแอป
