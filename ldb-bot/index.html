บอทถอนอัตโนมัติ

โปรแกรมกดโอนเงินให้ลูกค้าเอง ตามคิวถอนในระบบ

ใช้ทุกวัน — แค่ 3 ขั้น
1
เสียบสายมือถือเข้าคอม
มือถือเครื่องที่มีแอป LDB · เสียบสาย USB
🔌
2
ดับเบิลคลิกไฟล์ START
(ชื่อไฟล์ “เริ่มบอท”) ในโฟลเดอร์บอท · คลิก 2 ที เท่านั้น
🖱️
3
เสร็จ! บอททำงานเอง
มันจะกดโอนตามคิวให้เรื่อย ๆ · อยากหยุด = ปิดหน้าต่างสีดำ
✅
🛡️

ปลอดภัย ไม่ต้องเฝ้า — ก่อนกดโอนทุกครั้ง บอทเช็ค ชื่อผู้รับ + เลขบัญชี + ยอดเงิน ให้ตรงกับใบถอนก่อนเสมอ ถ้าไม่ตรง มันจะไม่โอน แล้วส่งให้คนตรวจแทน

ตั้งครั้งแรก · ทำครั้งเดียว
🔧 ตั้งครั้งแรก (ให้ช่าง หรือ เจ้าของ ทำ)
ทำครั้งเดียวตอนแรกสุด · คนใช้งานทุกวันไม่ต้องยุ่งกับส่วนนี้
⬇️ โหลดบอทถอน LDB
แตกไฟล์ Vela-LDB-Bot.zip แล้ววางในคอม (โฟลเดอร์เดียวกับ adb)
ยังต้องมี adb ด้วย → โหลด adb จาก Google
1
เอาโฟลเดอร์บอทไปวางในคอม
วางรวมกับ adb (โฟลเดอร์ platform-tools) ให้อยู่ที่เดียวกัน
2
ลง Python หนึ่งครั้ง
winget install Python.Python.3.12
3
เปิด USB debugging ในมือถือ
ตั้งค่า → เกี่ยวกับโทรศัพท์ → แตะ “หมายเลขบิลด์” 7 ครั้ง → ตัวเลือกนักพัฒนา → เปิด USB debugging → เสียบสาย → กด “อนุญาต” บนมือถือ
4
ใส่ค่าที่หน้าตั้งค่า Vela
การ์ด “บอทถอนอัตโนมัติ (LDB)” → รุ่นมือถือ + บัญชีต้นทาง + PIN + เพดาน
5
สร้างไฟล์ config.json
ก๊อปจาก config.example.json แล้วใส่ feed_token + feed_secret (เอาจากหน้า Vela)
6
ดับเบิลคลิก SETUP ทีนึง (ชื่อไฟล์ “ตั้งค่าครั้งแรก”)
มันจะเช็คมือถือ + ลงคีย์บอร์ดพิมพ์ให้เอง · เห็น “device” และ “Success” = พร้อม
🔒

ก่อนเปิดจ่ายจริง: รันแบบ “ทดสอบ” (dry_run) ก่อน ดูว่าบอทตรวจถูกใบ แล้วค่อยเปิดสวิตช์จ่ายจริงที่หน้า Vela — ให้ช่าง/เจ้าของเป็นคนสลับ
