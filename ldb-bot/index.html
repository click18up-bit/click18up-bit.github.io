ตัวบอทเอง · ได้ไฟล์ Vela-LDB-Bot.zip (24 ไฟล์)
⬇️ ไฟล์ที่ 2 · ตัวเชื่อมมือถือ (adb)
ตัวที่ทำให้คอมสั่งงานมือถือได้ · ของ Google ได้ไฟล์ชื่อ platform-tools
โหลดครบทั้ง 2 ไฟล์ แล้วเอามารวมกันในขั้นที่ 1 ข้างล่าง
1
รวมไฟล์ไว้โฟลเดอร์เดียว

แตกไฟล์ zip ทั้ง 2 อัน (คลิกขวาไฟล์ → แตกไฟล์ / Extract)

  1. ไฟล์ที่ 2 (adb) แตกออกมา จะได้โฟลเดอร์ชื่อ platform-tools — ข้างในมี adb.exe
  2. เอาไฟล์ของบอท (จากไฟล์ที่ 1) ทั้งหมดไปวางในโฟลเดอร์ platform-tools นี้ ให้อยู่รวมกัน

สุดท้ายในโฟลเดอร์เดียวควรมี: adb.exe · START.bat · SETUP.bat · ใส่รหัส.bat · _find.bat · ldb_agent.py · config.json · ADBKeyboard.apk · โฟลเดอร์ msg

⚠️

ต้องเอาไปให้ครบ โดยเฉพาะโฟลเดอร์ msg กับไฟล์ _find.bat — ถ้าลืม หน้าจอจะขึ้นว่า “The system cannot find the file” แทนข้อความภาษาไทย

💾

วางไดร์ไหนก็ได้ — จะเป็น C:, D:, E: หรือแฟลชไดร์ก็ได้ ไม่จำเป็นต้องเป็นไดร์ C · โปรแกรมหาที่อยู่ตัวเองอัตโนมัติ ขอแค่ไฟล์ทุกอย่างอยู่โฟลเดอร์เดียวกัน

2
ลง Python
โปรแกรมที่ทำให้บอทรันได้

ลงครั้งเดียวพอ · วิธีง่ายสุด: เปิด Microsoft Store → ค้นหา “Python 3.12” → กด Get / ติดตั้ง

หรือถ้าถนัดพิมพ์คำสั่ง: เปิด Command Prompt แล้วพิมพ์

winget install Python.Python.3.12
🔁

ลงเสร็จต้องปิดหน้าต่างดำทุกอัน แล้วเปิดใหม่ — หน้าต่างที่เปิดค้างไว้ตั้งแต่ก่อนลง จะยังมองไม่เห็น Python แล้วฟ้องว่ายังไม่ได้ลง ทั้งที่ลงแล้ว

อยากเช็คว่าลงสำเร็จไหม: เปิด Command Prompt ใหม่ แล้วพิมพ์ python --version ต้องขึ้นเลขเวอร์ชัน เช่น Python 3.12.6

3
เปิดโหมดต่อคอมในมือถือ
USB debugging
  1. ตั้งค่า → เกี่ยวกับโทรศัพท์ → แตะ “หมายเลขบิลด์” รัว ๆ 7 ครั้ง
  2. กลับไปตั้งค่า → ตัวเลือกสำหรับนักพัฒนา → เปิด “การแก้จุดบกพร่อง USB”
  3. เสียบสาย USB → มือถือเด้งถาม → กด “อนุญาต” (ติ๊ก “เสมอ” ด้วย)
4
ตั้งค่าที่หน้า Vela
บนเว็บแอดมิน

เข้าแอดมิน Vela → เมนู ตั้งค่า → การ์ด “บอทถอนอัตโนมัติ (LDB)” แล้วกรอก:

  • รุ่นมือถือ (Oppo A3x) · บัญชีต้นทาง LDB (เลขบัญชี + ชื่อ)
  • PIN สำหรับกดโอน · เพดานเงินต่อครั้ง/ต่อวัน
5
ใส่รหัส — ดับเบิลคลิก ใส่รหัส
เขียนไฟล์ให้เอง

หารหัสที่ไหน: เข้าเว็บแอดมิน Vela → เมนู ตั้งค่า → การ์ด “บอทถอนอัตโนมัติ (LDB)” → กดแถบ “🔑 รหัสสำหรับใส่ในบอท” → มีปุ่มก๊อป 2 ค่า: feed_token · feed_secret

  1. ดับเบิลคลิกไฟล์ “ใส่รหัส”
  2. มันถามทีละค่า — คลิกขวาในหน้าต่างดำ = วาง แล้วกด Enter (URL กด Enter ผ่านได้เลย)
  3. ขึ้น “เชื่อมต่อผ่าน — รหัสถูกต้อง” = เสร็จ · ถ้าขึ้นแดง = ก๊อปรหัสผิด ก๊อปใหม่แล้วรันซ้ำ
✋

ไม่ต้องเปิด config.json แก้เองด้วย Notepad — แก้มือพลาดง่าย (ลืมลบ <<>> / Windows แอบเติม .txt) แล้วบอทฟ้อง error งง ๆ ให้ใช้ปุ่ม “ใส่รหัส” เท่านั้น

feed_secret เป็นรหัสลับของร้าน อย่าให้หลุดออกนอก · แก้รหัสภายหลังก็ดับเบิลคลิก “ใส่รหัส” ซ้ำได้

6
ดับเบิลคลิก SETUP ทีนึง
ชื่อไฟล์ “ตั้งค่าครั้งแรก”

เสียบสายมือถือไว้ แล้วดับเบิลคลิก · โปรแกรมจะ เช็คว่าต่อมือถือได้ + ลงคีย์บอร์ดสำหรับพิมพ์ ให้เอง

เห็นคำว่า “device” และ “Success” = พร้อมใช้แล้ว
